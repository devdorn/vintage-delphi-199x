# vintage-delphi-199x

Welcome to my personal Delphi 4 time capsule.

## Motivation
I have opened my "Code Box" and am now storing rare code snippets and files for melancholic and humorous reasons. This repository captures my software development journey with Borland Delphi 4 in the late 1990s.

## Project Structure
- **[src/faktur](src/faktur)**: Commercial invoicing application logic.
- **[src/monat](src/monat)**: Monthly report generation and data processing.
- **[src/beispiele](src/beispiele)**: Early examples and learning units.
- **[src/test](src/test)**: Experimental UI tests and scratchpads.
- **[docs](docs)**: Technical research and archival findings.
- **[external/easycash-backup](external/easycash-backup)**: Third-party TBackupFile component and SFX examples by Alexander Halser (Easycash Software, 1998). Includes Zlib object files.
