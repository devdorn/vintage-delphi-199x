# Delphi 4 Project: Legacy Archive

## Motivation
This repository is part of a preservation effort to secure and organize legacy source code from the late 1990s. This specific collection contains applications and utilities developed using **Borland Delphi 4**. It represents a snapshot of Windows development during that era, focusing on commercial tools (Invoicing/Faktur) and various utility experiments.

## Project Structure
- `src/`: Original Delphi source files (.pas, .dfm, .dpr)
- `docs/`: Historical documentation and research notes
- `external/`: Third-party components or libraries (if any)

## Digital Archaeology & AI Declaration
This archive has been processed and structured with the assistance of AI (Antigravity). The goal is to maintain the original logic while applying modern repository standards for better accessibility and long-term preservation.

For more information on the methodology, visit: [Digitale Archäologie](https://github.com/bdorn/digitale-archaeologie)
